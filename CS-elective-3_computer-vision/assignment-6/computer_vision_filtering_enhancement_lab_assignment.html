Task 1

Spatial Noise Removal & Filter Selection Analysis

Weight: 35 Points

Objective

Compare linear (Box/Mean, Gaussian) and non-linear (Median) spatial filters quantitatively and qualitatively when restoring imagery corrupted by two distinct noise profiles: zero-mean additive Gaussian noise vs. impulse salt-and-pepper noise.

Quantitative Metrics Formulation

Mean Squared Error (MSE)

$$\text{MSE} = \frac{1}{M \times N} \sum_{i=0}^{M-1} \sum_{j=0}^{N-1} [I(i,j) - K(i,j)]^2$$

Peak Signal-to-Noise Ratio (PSNR)

$$\text{PSNR} = 10 \cdot \log_{10} \left( \frac{\text{MAX}_I^2}{\text{MSE}} \right)$$

Implementation Requirements

  1. Load a clean grayscale reference image and generate two corrupted test images:
    • Additive Gaussian Noise: Zero mean ($\mu = 0$) with standard deviation $\sigma = 25$.
    • Impulse Noise: Salt-and-pepper noise affecting $5\%$ of total image pixels.
  2. Apply a $5 \times 5$ Box Filter (cv2.blur), $5 \times 5$ Gaussian Filter ($\sigma=0$), and $5 \times 5$ Median Filter (cv2.medianBlur) to both noisy images.
  3. Calculate PSNR and MSE between the restored outputs and the clean ground-truth image.
  4. Construct a $2 \times 4$ Matplotlib subplot grid comparing original, noisy, and filtered images with their calculated PSNR scores explicitly printed in the subplot headers.
Starter Python Implementation 
import cv2
import numpy as np
import matplotlib.pyplot as plt

def compute_psnr(original, filtered):
    """Computes Peak Signal-to-Noise Ratio (PSNR) between two images."""
    mse = np.mean((original.astype(np.float64) - filtered.astype(np.float64)) ** 2)
    if mse == 0:
        return float('inf')
    max_pixel = 255.0
    return 10 * np.log10((max_pixel ** 2) / mse)

Task 2

Frequency Domain Band-Pass Filter Design

Weight: 35 Points

Objective

Construct custom 2D spectral frequency masks using the Discrete Fourier Transform (DFT) to isolate specific spatial frequency bands. Evaluate the visual and mathematical differences between **Ideal Band-Pass** and **Butterworth Band-Pass** filters.

Transfer Functions

Ideal Band-Pass Filter Mask $H_{\text{IBP}}(u,v)$

$$H_{\text{IBP}}(u,v) = \begin{cases} 1 & \text{if } D_0 \le D(u,v) \le D_1 \\ 0 & \text{otherwise} \end{cases}$$

Butterworth Band-Pass Mask $H_{\text{BBP}}(u,v)$ ($n$-th order)

$$H_{\text{BBP}}(u,v) = 1 - \frac{1}{1 + \left( \frac{D(u,v) \cdot W}{D(u,v)^2 - D_0^2} \right)^{2n}}$$

Implementation Requirements

  1. Compute the 2D DFT of a grayscale image using cv2.dft(..., flags=cv2.DFT_COMPLEX_OUTPUT) and shift the DC zero-frequency component to the array center via np.fft.fftshift().
  2. Construct a 2-channel 2D **Ideal Band-Pass Filter Mask** with inner cutoff radius $D_0 = 15$ and outer cutoff radius $D_1 = 60$.
  3. Construct a 2-channel 2D **Butterworth Band-Pass Filter Mask** of order $n=2$ using identical radial cutoffs.
  4. Perform element-wise spectral multiplication (fshift * mask), apply inverse DC shift (np.fft.ifftshift), compute Inverse DFT (cv2.idft), and derive spatial magnitude outputs using cv2.magnitude().

Task 3

Custom Unsharp Masking Pipeline (From Scratch)

Weight: 30 Points

Objective

Implement an edge-enhancing **Unsharp Masking** pipeline from first principles without using high-level cv2 sharpening wrappers. Explore parameter tuning across Gaussian blur scales ($\sigma$) and high-boost scaling factors ($k$).

Unsharp Masking Formulation
$$g(x,y) = f(x,y) - f_{\text{smooth}}(x,y)$$ $$f_{\text{sharp}}(x,y) = f(x,y) + k \cdot g(x,y)$$

where $g(x,y)$ represents the isolated high-frequency detail signal and $k \ge 0$ is the amplification gain factor.

Implementation Requirements

  1. Define a custom Python function unsharp_mask(image, kernel_size, sigma, k).
  2. Generate the smoothed low-pass base image $f_{\text{smooth}}$ using a Gaussian spatial filter (cv2.GaussianBlur).
  3. Subtract the blurred image from the original signal to isolate the high-frequency unsharp mask $g(x,y)$.
  4. Add the scaled mask $k \cdot g(x,y)$ back to the original image array, applying np.clip(..., 0, 255) and casting to np.uint8.
  5. Compare your custom unsharp mask output against direct spatial convolution using the discrete high-boost Laplacian matrix: $$\begin{bmatrix} 0 & -1 & 0 \\ -1 & 5 & -1 \\ 0 & -1 & 0 \end{bmatrix}$$
Starter Python Implementation 
import cv2
import numpy as np
import matplotlib.pyplot as plt

def unsharp_mask(img, kernel_size=(5, 5), sigma=1.0, k=1.5):
    """
    Applies custom Unsharp Masking enhancement to a grayscale image.
    """
    # 1. Smooth signal with Gaussian low-pass filter
    blurred = cv2.GaussianBlur(img, kernel_size, sigma)
    
    # 2. Subtract smooth signal to isolate high-frequency edges
    mask = img.astype(np.float32) - blurred.astype(np.float32)
    
    # 3. Scale and add back to original image
    sharpened = img.astype(np.float32) + (k * mask)
    
    # 4. Handle overflow/underflow clipping
    return np.clip(sharpened, 0, 255).astype(np.uint8)

# Load input image
img = cv2.imread('input.jpg', cv2.IMREAD_GRAYSCALE)

# Evaluate across multiple amplification factors k
sharpened_k05 = unsharp_mask(img, k=0.5)
sharpened_k15 = unsharp_mask(img, k=1.5)
sharpened_k25 = unsharp_mask(img, k=2.5)
