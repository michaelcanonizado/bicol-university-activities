=== Final Reflection — Geometric vs. Intensity Transformation ===
Situation A is a geometric transformation because the image is moved 100 pixels to the right, changing the positions of the objects. Situation B is an intensity transformation because the pixel values become brighter while their positions remain the same.
This is an intensity transformation because only the pixel intensity values are changed. The objects remain in their original positions.
Intensity transformation is a process of changing the brightness or intensity of pixels in an image. It does not move the objects or change their positions in the image. Instead, it changes how light or dark the pixels appear. For example, increasing brightness makes the pixels lighter, while decreasing brightness makes them darker. Contrast adjustment changes the difference between dark and bright areas. Negative transformation reverses the brightness values, while thresholding changes pixels into black or white based on a specific value. These transformations can make important parts of an image easier to see and analyze.
Intensity transformation can make objects and important features easier to see in an image. It can improve object detection, segmentation, and feature extraction by making differences between objects and their backgrounds more noticeable.
